# ADR-0003 — Fontes de dados de alimentos

- **Status:** Aceito com condição (14/11/2026)
- **Contexto:** A especificação exige fontes reconhecidas e respeito às licenças (RN-10, RN-11).
- **Fatos levantados:**
  - **TACO:** reprodução total ou parcial permitida com citação da fonte. Não há cláusula explícita sobre uso comercial.
  - **TBCA:** fontes secundárias indicam licença paga para incorporar a base em outras ferramentas.
- **Decisão:**
  - Fase 1 usa apenas a TACO, com citação.
  - Uso em **produção** condicionado à confirmação por escrito do NEPA/UNICAMP.
  - A TBCA só será usada com contrato de licença.
- **Consequências:** Banco inicial mais limitado (cerca de 600 alimentos). Os alimentos privados das organizações (RN-13) compensam parte da lacuna.
